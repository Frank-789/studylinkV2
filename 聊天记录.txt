# 学脉(StudyLink) AI教育智能体实施计划

## 上下文
用户需要开发一个AI教育智能体"学脉(StudyLink)"，这是一个面向大学生的AI知识导航平台。核心功能是输入关键词/目标，输出知识图谱+行动路径。用户提供了详细的项目文档，要求实现所有文档中提到的功能，但技术细节可以自由选择。已提供DeepSeek API Key，最终产品需以网站形式呈现（类似www.studylink.ai），UI要求高级、简洁、美观。

## 核心需求分析
基于项目文档分析，必须实现以下功能：

### P0优先级（必须有）
1. **智能知识图谱引擎**
   - 输入关键词，输出四层可视化知识网络：
     - 核心概念层：定义解析、核心要素、关联概念
     - 学习资源层：课程、论文、教材推荐
     - 实践应用层：竞赛案例、岗位JD、实际案例
     - 人脉资源层：核心学者、学长推荐、行业专家
   - 可视化交互：点击展开、缩放、筛选

2. **基础搜索+语义理解**
   - 支持关键词搜索
   - 语义理解（理解用户真实意图）
   - 语音输入支持

### P1优先级（重要）
3. **个性化学习路径生成**
   - 输入目标，输出14天学习计划
   - 包含每日任务清单、推荐学习资源、自测题和检查点

4. **竞赛/岗位信息推送**
   - 基于专业+兴趣的竞赛推荐
   - 升学信息（考研/保研/留学）
   - 岗位匹配（技能分析）

### P2优先级（可延后）
5. **学习沙盒（个人知识库）**
6. **打卡与激励系统**
7. **人脉撮合系统**

## 技术方案

### 技术栈选择
**前端：**
- React + TypeScript（构建复杂交互应用）
- Ant Design / Chakra UI（UI组件库）
- D3.js + ECharts（知识图谱可视化）
- Zustand（状态管理）

**后端：**
- FastAPI（Python，高性能异步框架）
- PostgreSQL（关系数据存储）
- Neo4j（图数据库，存储知识图谱）
- Redis（缓存层）
- Celery（异步任务处理）

**AI集成：**
- DeepSeek API（主要AI模型，用户已提供API Key）
- 备用模型：智谱AI GLM-4 / 通义千问
- 向量数据库：Qdrant（用于语义搜索增强）

**部署与运维：**
- Docker + Docker Compose（容器化部署）
- Nginx（反向代理+负载均衡）
- 阿里云/腾讯云学生服务器
- Prometheus + Grafana（监控）
- ELK Stack（日志管理）

### 系统架构
分层架构：
1. **用户层**：Web端（React）、移动端H5、微信小程序（可选）
2. **API网关层**：Nginx反向代理
3. **应用服务层**：FastAPI微服务（搜索服务、路径服务、推荐服务）
4. **数据服务层**：PostgreSQL + Neo4j + Redis
5. **外部服务层**：DeepSeek API、爬虫服务、OSS存储

### UI/UX设计
**设计理念：** 简洁现代、科技感、教育感、响应式

**配色方案：**
- 主色：`#4F46E5`（靛蓝色）- 代表知识、专业
- 辅色：`#10B981`（翠绿色）- 代表成长、活力
- 强调色：`#F59E0B`（琥珀色）- 代表重点、提醒
- 背景：`#F9FAFB`，文字：`#1F2937`

**核心页面：**
1. **首页**：大型搜索框、热门概念轮播、功能特性展示
2. **知识图谱页**：左侧图谱可视化，右侧详细信息面板
3. **学习路径页**：时间轴布局，每日任务卡片
4. **个人中心**：学习统计、收藏夹、设置

## 实施路线图

### 阶段1：MVP开发（4-6周）
**目标：** 实现P0和P1核心功能

**第1-2周：基础架构搭建**
- 项目初始化，技术栈配置
- 数据库设计（PostgreSQL表结构，Neo4j图模型）
- FastAPI基础框架，基础API端点
- Docker容器化配置

**第3-4周：核心功能开发**
- 知识图谱引擎：搜索API、图谱构建、可视化组件
- AI集成：DeepSeek API封装，Prompt模板设计
- 基础数据：整理1-2个专业示例数据

**第5-6周：前端开发与集成**
- React前端页面开发（首页、图谱页、路径页）
- API对接与联调测试
- 性能优化与缓存策略实现

### 阶段2：功能完善（3-4周）
**目标：** 完善P1功能，开始P2功能

**第7-8周：个性化功能**
- 学习路径生成算法优化
- 推荐系统开发（竞赛、岗位、资源推荐）
- 用户系统（登录、收藏、学习历史）

**第9-10周：数据扩展**
- 爬虫系统开发（课程、论文、竞赛数据采集）
- 数据清洗与入库
- 知识图谱扩展（覆盖3-5个热门专业）

### 阶段3：优化与部署（2-3周）
**目标：** 性能优化，上线准备

**第11-12周：性能优化**
- 缓存策略优化（Redis多级缓存）
- 图谱查询性能优化（Neo4j索引、查询优化）
- 前端性能优化（懒加载、代码分割）

**第13周：部署上线**
- 服务器配置（阿里云/腾讯云学生机）
- 域名备案与SSL证书（www.studylink.ai）
- 监控系统部署（Prometheus、Grafana）
- 上线测试与验证

## 关键文件
基于现有文档和设计，以下是最关键的实现文件：

1. **后端AI服务**：`/backend/app/services/ai_service.py` - DeepSeek API封装
2. **知识图谱服务**：`/backend/app/services/graph_service.py` - 图谱构建与查询
3. **前端图谱组件**：`/frontend/src/components/KnowledgeGraph/GraphVisualization.tsx` - 可视化组件
4. **搜索API**：`/backend/app/api/search.py` - 处理搜索请求
5. **图数据模型**：`/backend/app/models/graph_models.py` - Neo4j模型定义

## 部署方案
**服务器配置：**
- CPU：2核，内存：4GB，硬盘：40GB SSD
- 月费用：约¥100（学生优惠）

**Docker部署：**
使用docker-compose编排后端、前端、PostgreSQL、Neo4j、Redis、Nginx服务。

**域名配置：**
- 主域名：www.studylink.ai
- SSL证书：Let's Encrypt免费证书
- CDN：阿里云/腾讯云CDN加速静态资源

## 验证测试
**功能验证：**

**用户体验测试：**

- 交互流畅性测试
- 移动端适配测试

## 风险与应对
1. **AI调用成本**：通过缓存、用户限额、本地规则引擎控制
2. **知识图谱准确性**：人工审核、用户反馈、多源验证

'use client'

import { useState } from 'react'
import { Search, Mic } from 'lucide-react'

interface SearchBarProps {
  onSearch: (query: string) => void
  isLoading: boolean
}

export default function SearchBar({ onSearch, isLoading }: SearchBarProps) {
  const [query, setQuery] = useState('')

  const handleSubmit = (e: React.FormEvent) => {
    e.preventDefault()
    if (query.trim()) {
      onSearch(query.trim())
    }
  }

  const handleVoiceInput = () => {
    if ('webkitSpeechRecognition' in window) {
      const recognition = new (window as any).webkitSpeechRecognition()
      recognition.lang = 'zh-CN'
      recognition.onresult = (event: any) => {
        const transcript = event.results[0][0].transcript
        setQuery(transcript)
        onSearch(transcript)
      }
      recognition.start()
    } else {
      alert('您的浏览器不支持语音输入')
    }
  }

  return (
    <form onSubmit={handleSubmit} className="w-full">
      <div className="relative">
        <div className="absolute left-4 top-1/2 transform -translate-y-1/2 text-muted">
          <Search size={20} />
        </div>
        <input
          type="text"
          value={query}
          onChange={(e) => setQuery(e.target.value)}
          placeholder="输入任何学习概念、课程名称或职业目标..."
          className="input-primary pl-12 pr-24 py-4 text-lg"
          disabled={isLoading}
        />
        <div className="absolute right-2 top-1/2 transform -translate-y-1/2 flex items-center space-x-2">
          <button
            type="button"
            onClick={handleVoiceInput}
            className="p-2 hover:bg-gray-100 rounded-full transition-colors"
            title="语音输入"
          >
            <Mic size={20} className="text-muted" />
          </button>
          <button
            type="submit"
            disabled={isLoading || !query.trim()}
            className="btn-primary px-6 py-2"
          >
            {isLoading ? '搜索中...' : '智能搜索'}
          </button>
        </div>
      </div>
      <div className="mt-4 text-sm text-muted flex justify-between">
        <span>支持中文关键词、完整问题、学习目标</span>
        <span>示例：机器学习入门、参加数学建模竞赛、数据分析师技能</span>
      </div>
    </form>
  )
}

import { NextRequest, NextResponse } from 'next/server'
import { queryDeepSeek } from '@/lib/deepseek'

export async function POST(request: NextRequest) {
  try {
    // 解析请求体
    const body = await request.json()
    const { query } = body

    if (!query || typeof query !== 'string') {
      return NextResponse.json(
        { error: '请输入有效的查询内容' },
        { status: 400 }
      )
    }

    // 设置响应头，支持CORS
    const headers = new Headers({
      'Content-Type': 'application/json',
      'Access-Control-Allow-Origin': '*',
      'Access-Control-Allow-Methods': 'POST, OPTIONS',
      'Access-Control-Allow-Headers': 'Content-Type, Authorization'
    })

    // 调用DeepSeek API获取响应
    const response = await queryDeepSeek(query)

    // 记录API使用情况
    console.log(`API调用: ${query} - 响应时间: ${Date.now()}ms`)

    return NextResponse.json(response, { headers })
  } catch (error) {
    console.error('搜索API错误:', error)

    // 返回错误响应，但仍然提供示例数据
    const query = await request.json().then(data => data.query).catch(() => '未知查询')

    const fallbackResponse = {
      query,

        nodes: [
          { id: 'query', name: query, type: 'concept' },
